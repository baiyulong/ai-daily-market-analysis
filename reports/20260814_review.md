## 五、风控与仓位（risk）

| 项目 | 建议 |
|---|---|
| **总仓位上限** | **两成以下（≤20%）**；繁荣分歧期 + 退潮预判中，防守为主 |
| **单笔仓位** | 10%-15%（方法论基准 20%，分歧期降档）；仅低位确认标的（共进/神奇打板确认）可放宽至 20% |
| **持仓结构** | 分仓为主不集中：单票不超 20%，同方向（算力/医药）合计不超 30% |
| **加仓规则** | 每次加仓需新超预期确认，单票最高 60%；做错不补仓；被动进攻票（蓝盾/人民同泰）一律不加仓 |

**全局退出信号**：
1. 核按钮扩散至 ≥3 家 → 空仓观望
2. 出现二连跌停 → 方法论确认退潮，空仓至两成以下甚至清仓
3. 炸板率继续升破 35% → 降仓
4. 跌停家数扩至 20+ → 空仓
5. 医药高标竞价深水 + 亨通大幅低开破位（双主线同弱）→ 空仓观望
6. 蓝盾光电低开/断板/核按钮 → 退潮确认，全场降仓至一成以下

## 六、明日（2026-08-17 周一）三种预期预案

### 正常预期（高位退潮延续但温和）
- 仓位两成以下，只做**低位确认标的**：共进股份/神奇制药 2板竞价不弱可打板确认（20% 上限）。
- 算力大票亨通/剑桥/网宿高开回踩不破位可低吸（10-15%）。
- Pass 跟风杂毛；前排强转弱慢慢兑现。

### 低于预期（亏钱效应加速扩散）
- 触发条件：核按钮 ≥3 个 / 医药高标深水 / 亨通破位 / 蓝盾断板 / 跌停 20+。
- **空仓观望，仓位 0-一成**；不抄底、不补仓、不打板；等二连跌停确认退潮后的冰点信号。

### 高于预期（分歧转一致）
- 触发条件：蓝盾晋级 6 板或断板高标再晋级 / 医药算力分歧转一致 / 亨通低开拉回 / 炸板率回落 25% 以下 / 跌停收敛 5 家内。
- 仓位可提至三成（不超）；算力大票低开拉回可低吸加仓，低位 2板打板确认可执行；加仓需新超预期确认，不追高标。
