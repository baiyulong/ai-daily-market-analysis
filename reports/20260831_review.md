## 二、市场风格判定

### 结论：**概念炒作**（置信度：high）

### 核心理由

1. **涨停板归属**：90只涨停中AI(16)/华为(12)/机器人(11)/国改(10)/算力(10)/芯片(9)等纯概念方向占绝对多数，这些题材**短期均无法算出业绩兑现**——涨停集中在概念方向是判定概念炒作的首要证据。

2. **连板梯队属性**：6板海鸥住工(家居/国改)、5板万向德农(种业)/捷荣技术(消费电子)、4板锦龙股份(券商)、3板新赛/沃特/星网锐捷——**全部为概念属性，无一只有明确产能/订单/价格暴涨驱动**，无法推导业绩弹性。

3. **医药线崩塌特征**：4只恐慌性跌停（冀衡4板→跌停、神奇12天7板跌停、开开17天8板跌停、汉森8天5板跌停），高位股不计成本按死——**概念炒作退潮的典型A杀**，基本面炒作走趋势+反包可持续季度到半年，不会出现这种走势。

4. **资金切换性质**：医药退潮→消费/影视扩散（华策影视+15.77%但未涨停），是**情绪轮动而非基本面驱动**。

5. **缺乏可量化催化剂**：无产品价格暴涨/产能释放/订单暴增数据。

6. **情绪周期退潮信号**：封板率62.9%跌破65%警戒线，炸板53只连续2日上升，跌停10只——亏钱效应扩散，概念炒作周期末端特征。

### 关键退出信号（Critical级）
1. **医药线4只恐慌性跌停任一连跌停** → 退潮升级"猛烈"，**立即清仓**
2. **海鸥住工7板封单<1.5亿或竞价低开3%+** → 新龙头失败=退潮加剧，**清仓所有仓位**

4. **跌停家数扩大至15+或恐慌性跌停二连跌停** → **清仓所有仓位**
5. **做错不补仓**：持仓票当日亏损-7%+且无明确反转信号 → 立即止损，不补仓
6. **龙头恶劣复牌**（天地板/冲高七八个点后一根线打到底）→ 同路线短线票跟着砸，退出

### 退潮期纪律
1. 退潮期从严：总仓位两成以下甚至空仓观望，参与度因子0.1只观察不重仓打板
2. 做错不补仓：亏损-7%+且无明确反转信号立即止损
3. 被动进攻易主动调整：享受情绪溢价的跟风股，分歧来临最先扛不住
4. 龙头恶劣复牌必退出：天地板/冲高七八个点后一根线打到底→同路线跟着砸
5. 强转弱兑现：弱转强后再次强转弱→卖
6. 补涨龙退场：龙头连续两个跌停→补涨龙也该散了
7. 不抄底旧龙头：深中华A类见顶标的不参与不抄底

### 禁止操作
追高烂板 / 抄底旧龙头 / 参与医药线 / 补仓 / 重仓打板 / 在封板率<60%环境打板 / 追高跟风被动进攻 / 抄底恐慌性跌停 / 盲目信任"机构净买" / 跨年妖盲目画饼

- 海鸥住工7板位=最大不确定性（6进7历史失败率高+4只恐慌性跌停+退潮确认）
- 深中华A继续下跌-3%+=旧龙头不反包传导至跟风股补跌
- 封板率62.9%跌破65%警戒线+炸板53家连续2日上升+跌停10家=情绪环境恶化
- 医药线5只跌停全线崩塌=最重亏钱方向，若明日连跌停扩散则全市场退潮加剧
